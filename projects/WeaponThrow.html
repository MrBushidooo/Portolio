Project Overview

A third-person weapon throw and recall system built in Unreal Engine 5 using C++ and Blueprints, focused on creating responsive and satisfying action combat interactions inspired by modern melee combat games. The project features throwable weapon mechanics with collision-based damage, spline-based return movement, hover behaviour, and dynamic recall back to the player’s hand.

The system was designed as a reusable gameplay framework capable of handling weapon travel, impact detection, gameplay state transitions, and smooth visual feedback while maintaining strong gameplay feel and combat responsiveness. Custom movement logic and spline interpolation were implemented to create fluid return trajectories that dynamically adapt to player movement during recall.

Core Features & Systems

Weapon Throw System

Forward throw mechanic implemented using custom projectile-style movement. The weapon travels independently after launch while maintaining directional momentum and collision detection.

Weapon Recall System

Spline-based recall movement dynamically updates the weapon trajectory back toward the player's hand socket. Return behaviour smoothly tracks player movement during recall to maintain responsive gameplay feel.

Hover State

Implemented a temporary hover state where the weapon pauses mid-air before recall. This state creates stronger anticipation and improves combat readability during gameplay interactions.

Collision Damage System

Enemy collision detection applies damage on impact while preventing repeated damage triggers during continuous overlap. Hit events are handled through dedicated damage logic and gameplay state checks.

Weapon State Management

Weapon behaviour is controlled using gameplay states such as idle, thrown, hovering, and returning. State-driven logic ensures clean transitions between mechanics and simplifies future system expansion.

Weapon Rotation & Visual Feedback

Added procedural weapon rotation during travel to enhance motion readability and combat impact. Visual feedback systems improve the perceived weight and responsiveness of the weapon during throw and recall actions.
